One line, best line: a single sentence of at most 240 characters on a free
and entertaining theme, judged pairwise by an AI judge on whether it stops
the scroll, is genuinely entertaining, lands in one sentence with a punch
at the end, and feels fresh.

The line:

> My smart fridge texted 'we need to talk,' so now I'm standing in the
> kitchen wondering which one of us is getting replaced.

A breakup text from an appliance: the hook lands in the first words, the
whole idea arrives in one sentence, and the turn at the end flips who is
being replaced — the owner, not the fridge.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, stdlib only) writes the line to `entry.txt` in the
output directory, with no trailing newline so the file is exactly one
line. It validates the gate itself: 1–240 characters, a single line, not
only white space.
